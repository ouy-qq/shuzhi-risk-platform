# 数智观险：AI科创企业风险预演仿真原型

本仓库为挑战杯研究项目的公开静态平台，部署于 GitHub Pages。

## 核心功能

- 风险驾驶舱：展示80家样本企业、2026年前瞻风险分布和核心验证结果。
- 研究框架：呈现40→19项指标筛选、三引擎方法、组合权重及稳健性分析。
- 企业画像：查看80家企业的前瞻概率、文本证据和分层建议。
- 决策模拟：展示数据港与东土科技的双案例研判。
- 人工二审：检索320条证据，查看来源、锚点、模型概率、终标及误判。
- 报告生成：生成可打印/保存PDF的一页式风险画像报告，并下载HTML或JSON底稿。
- 模型卡：披露验证设计、参数、局限与使用边界。

## 口径说明

平台中的2026年结果属于前瞻预测，因真实结果尚不可观测，不用于验证模型准确率。NLP指标衡量候选风险语义单元三分类，而非整份年报的端到端风险召回。320条文本为语义凝练，不是逐字原文；采用人工二审复核，不主张双盲独立双标。平台仅供竞赛研究与风险筛查，不构成监管认定、信用评级或投资建议。

## 本地运行

```bash
python -m http.server 8000
```

浏览器访问 `http://localhost:8000/`。
